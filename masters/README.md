# Masters Page

صفحة مستقلة باسم `masters` لموقع SaifKS.

## التشغيل
افتح `index.html` مباشرة، أو ارفع مجلد `masters` كاملاً إلى الموقع.

## المحتوى الحالي
- Valora
- صورة المتخصص
- Affinity من 0 إلى 100
- حاسبة Affinity وAdvancement
- حاسبة المهارات
- العربية والإنجليزية
- تصميم متجاوب للموبايل والآيباد والكمبيوتر

قاعدة البيانات موجودة كذلك داخل:
`data/specialists.json`
